# Shape an Undecided Task

Use this guide when the user has an area of interest but has not chosen the
outcome, audience, or decision the work should serve.

Reflect the idea back in plain language, then surface only the genuinely distinct
directions that would lead to different work. Explain the important tradeoffs and
ask the user to choose or narrow a direction. Make a recommendation when the
available context supports one, and label it as a recommendation rather than a
fact about the user's intent.

End with a concise statement of the decided goal, audience, and angle. Build a
brief next only when the user asks for one or the task needs it; task shaping can
be a complete result by itself. Do not force exploration when the user's goal is
already clear.
