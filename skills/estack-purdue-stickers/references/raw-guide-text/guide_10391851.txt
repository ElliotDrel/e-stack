##
Frequently Asked Questions

### Can I walk into the Knowledge Lab and print my sticker on the same day?

A print time must be requested and approved to print. To request a print time, go to the Request Print Time page <https://guides.lib.purdue.edu/c.php?g=1398872&p=10391399>.

### How many stickers am I allowed to print?

The number of stickers depends on the dimensions of the sticker and how many can fit with the maximum monthly allotment of 18x36in. There is no limit to any specific sticker size as long as it fits within the monthly allotment.

### Can I print/submit multiple sticker designs at one time?

We recommend limiting the number of individual designs you submit or print at one time. However, you can submit multiple designs in the same PDF file as long as each of the sticker images has be formatted according to the instructions on the Prep Your File page <https://guides.lib.purdue.edu/c.php?g=1398872&p=10391398>

### Where can I access Adobe Illustrator?

Adobe Illustrator can be accessed on computers in Purdue IT supported computer labs <https://lslab.ics.purdue.edu/icsWeb/LabMap?_gl=1*gx2gsi*_ga*NDQ5NTk4Njg2LjE3MTY5OTMxMjk.*_ga_PF1CYQ27F6*MTcxNzYwODA0NC45LjEuMTcxNzYwODEyMi4wLjAuMA..>.
