# Submitting to the Knowledge Lab

Submission happens **through the Lab's booking website** — that is the required route. Open it for Elliot (Claude-in-Chrome tools if available, else give the link) and walk it together.

## The booking-site walkthrough

1. Open https://calendar.lib.purdue.edu/space/182313 (LibCal "Sticker Printer" space).
2. Click Next Available and pick green slot(s). Duration = 30 min per 12 in of roll length (30/60/90 min for <=12 / 12-24 / 24-36 in).
3. The request form asks for: the prepped file upload — upload BOTH the prepped PDF and the original image files (per the official video) — plus the material/finish choice (Glossy / Matte / Transparent; a Heat Transfer option may also appear — confirm on the form, it isn't on the archived materials page).
4. Submit, then wait: approval confirms the slot; a denial lists the fixes needed. Print at the Knowledge Lab (WALC 3007) at the booked time.

Form fields can change; describe what's actually on screen rather than forcing this list.

## Email fallback (has worked in practice)

Elliot emailed final PNGs and they were used with little/no edits (archived as `../assets/examples/sticker_talk_less_ship_more - buildpurdue.png` and `../assets/examples/sticker_build_with_people - buildpurdue.png`, 384x384 RGBA — accepted despite being under 300 DPI at 2 in). Lab staff did the Illustrator prep. Booking a print slot on the site is still required either way.

Ready-to-fill template (attach the PNGs and any SVGs):

> To: knowledgelab@purdue.edu
> Subject: Sticker print request — {FirstName LastName}
>
> Hi Knowledge Lab team,
>
> I'd like to print {N} sticker design(s), attached: {list file names}.
> - Physical size: {W}x{H} in each
> - Finish: {Glossy / Matte / Transparent}
> - Copies wanted: {count} (within the monthly 18x36 in allotment)
>
> The attachments are PNGs — could you add the CutContour cut path during prep, or let me know if you need a prepped PDF instead? I've booked / will book a print slot on the calendar page.
>
> Thanks!
> {FirstName LastName}

## Constraints checklist before submitting

- [ ] Total material within the 18x36 in monthly allotment (club/org counts as one person); see SKILL.md Step 0 for the math
- [ ] Original artwork only; no Purdue trademarks without a license, no third-party logos/characters
- [ ] Not for sale / no mass production
- [ ] Each design individually prepped if multiple in one PDF; file named FirstName_LastName_Sticker
