# Phase 0: Discovery — Assets, Sponsor Profile, Packet Critique

Read `references/03-sponsorship-market.md` before this phase (and `references/01-hormozi-value-equation.md` if not already loaded). Run it as a conversation, a few questions per turn, not a form.

**Produces:** an asset inventory, a sponsor profile, and — if an existing packet/proposal/deck was provided — a critique. These become the first sections of the offer file in Phase 1.

## 0a. The org's why (one question, early)

Ask why the org exists, in one sentence that isn't "to run the event" — belief, not results (reference 06). If the user can't state it, note that and move on; a candidate why usually surfaces during the asset conversation.

## 0b. Asset inventory

Walk the categories and ask what the org actually has. Each claimed asset must pass two questions: *is it real* (deliverable this season, provable) and *what sponsor outcome does it serve* (serves none → cut). Unverified numbers get marked `[assumption — verify]`.

- **Audience access** — events, demo days, newsletters, community channels. Real numbers: how many people, what demographics, what engagement.
- **Recruiting pipeline** — resume books, intro dinners, first-look interviews. Usually the most valuable and most underpriced asset class for sponsors of talent-dense communities.
- **Content & reach** — social, video, blog, email list. Real engagement numbers only.
- **Brand association** — naming rights, "official X of Y", category exclusivity (an asset even when nothing else changes).
- **Product access** — sampling, placement, beta users, feedback sessions.
- **People's time** — founder intros, advisory sessions, speaking slots for the sponsor.
- **Proof & data** — post-event reports, testimonials, photos. The fulfillment report itself is a sellable asset.

Close with the gap questions from the research: what's missing that sponsors would want? What do comparable properties offer, and not offer, that this org could?

## 0c. Sponsor profile

If the answer to "who's the sponsor?" is "any company with money", coach it narrower — sponsors buy audiences, so the profile falls out of who wants *this* audience:

- Who gets direct value from this audience — as talent, customers, or users? Pick a primary segment; different profiles want different assets and tones.
- Who sponsors comparable properties, and who competes with those sponsors? ("If one bank has interest, I bet they all do.")
- Belief-fit: which candidates plausibly share the org's why? They go to the top.
- Who is the buyer inside the company (Brand, Marketing, BD, University Relations, CSR), and what is *that person* judged on? Their metric is the dream outcome the offer must serve.

Filter candidates through Hormozi's four market indicators (reference 01): pain reaching this audience, purchasing power, easy to target, growing. Weak on two or more → deprioritize, however exciting the logo.

Name 3–5 real example companies before leaving this step. Abstract profiles produce abstract offers.

## 0d. Critique of the existing packet (only if one exists)

Score every page against two lenses: the Value Equation (which lever does this page move? pages that move none — org history, mission essays, tier grids — get flagged) and the known packet mistakes in reference 03. Deliver a short per-page table (page → what it does now → which lever it fails → fix) plus one paragraph on the biggest single gap. Name the principle each failure violates, so the user learns the lens, not just the fixes.

## Exit check

Confirm before Phase 1: the why (or a marked placeholder), the inventory with real/unverified flags, the named sponsor profile with example companies, and the critique if applicable. Then `steps/step-1-offer.md`.
