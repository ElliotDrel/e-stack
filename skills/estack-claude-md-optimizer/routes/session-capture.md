# Capture Durable Session Guidance

Use this route when the user asks to record a lesson from the session or when a
correction clearly belongs in project instructions.

Distinguish durable guidance from a temporary task detail. A repeated correction
is strong evidence, but the user's explicit request or a confirmed project
decision can also justify an update. Do not manufacture a new rule from a single
tool error, a transient workaround, or an unverified inference.

Propose the smallest change that captures the lesson in the project's chosen
instruction file. Include the evidence or user wording that supports it. Apply
the change when the request authorizes it, then verify the edited content and any
reference it adds. If the session contains no durable guidance, say so clearly
and leave the file unchanged.
