# Assess Instruction Scale

Use this route when the user asks whether project instructions need routing,
supporting documents, or a different layout.

Inspect the actual sources of friction: distinct work domains, instructions that
must be loaded only for certain tasks, recurring misrouting, and links that no
longer reach their target. Count alone is not evidence that a routing system will
help.

If the current files are sufficient, explain why and leave the structure alone.
When routing would solve an observed problem, propose the smallest set of clear
pointers and explain what each one serves. Routing can coexist with a canonical
instruction file in either direction; do not require a resolver format, fixed
line count, or prescribed pointer direction.

Apply a structural change when the user has asked for it. Otherwise, present a
concrete proposal, check affected links, and explain how the new arrangement
stays current.
